# Runtime capability evidence

Snapshot date: **2026-08-27**
Herdr checkout: [`d79fd746a96ddb5642939c9727baefce642d78e6`](https://github.com/herdrdev/herdr/tree/d79fd746a96ddb5642939c9727baefce642d78e6) (`v0.8.2-36-gd79fd746`)

This note records only capabilities supported by the checked-out Herdr source or first-party OpenAI/Cursor documentation. “CLI parity unverified” means the vendor documentation does not make the relevant CLI guarantee; it does not mean the behavior is known to be absent.

## Does Herdr emit `pane.updated` for input?

**No direct `pane.updated` event is emitted for raw key/text/paste input or for `pane.send_input` in this checkout.**

- `pane.send_text`, `pane.send_input`, and `pane.send_keys` encode/write bytes and return without emitting an API event. ([source](https://github.com/herdrdev/herdr/blob/d79fd746a96ddb5642939c9727baefce642d78e6/src/app/api/panes.rs#L1501-L1543), [keys](https://github.com/herdrdev/herdr/blob/d79fd746a96ddb5642939c9727baefce642d78e6/src/app/api/panes.rs#L1617-L1639); [local](../../../ref/herdr/src/app/api/panes.rs))
- Raw client `Key`, `Text`, and `Paste` events are routed to key handling, text commit, or PTY paste without an event emission at that input boundary. ([source](https://github.com/herdrdev/herdr/blob/d79fd746a96ddb5642939c9727baefce642d78e6/src/app/mod.rs#L1736-L1885); [local](../../../ref/herdr/src/app/mod.rs))
- `pane.updated` exists for socket subscribers, but the checked-in `emit_pane_updated` call sites concern pane metadata tokens/presentation, Agent-name reconciliation, managed-launch reconciliation, or stripped terminal-title changes—not ordinary input. Agent status/end and pane focus use other event kinds. ([emitter](https://github.com/herdrdev/herdr/blob/d79fd746a96ddb5642939c9727baefce642d78e6/src/app/api.rs#L612-L661); [local](../../../ref/herdr/src/app/api.rs))
- `pane.updated` and high-volume output/layout events are deliberately excluded from manifest plugin hook event kinds. ([event schema](https://github.com/herdrdev/herdr/blob/d79fd746a96ddb5642939c9727baefce642d78e6/src/api/schema/events.rs#L286-L357); [local](../../../ref/herdr/src/api/schema/events.rs))

Consequently, Pika-Go cannot treat `pane.updated` as a faithful user-input heartbeat. A key binding may trigger a separate semantic state/focus/layout event, and input may later cause PTY output, but neither proves raw user input. The accepted MVP nevertheless uses `pane.updated` as a deliberately best-effort inactivity reset, exposes that limitation in status, and does not claim strict human-inactivity detection. Accurate activity tracking would require Pika-owned input-boundary instrumentation or a new upstream Herdr input event, both outside the accepted first-release scope.
