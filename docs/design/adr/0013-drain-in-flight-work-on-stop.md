# 达到停止条件后排空已在途工作

尝试预算在候选创建时计数，达到 `max_attempts` 或性能目标后不再创建新候选，但已运行和已排队归并的候选继续完成。多个性能目标默认全部满足才触发停止，Campaign 可显式改为任一目标；Plateau 默认不启用。若配置了主线复验，必须排空复验与 Revert 队列后才能标记 `Completed`，避免以尚未验证或可能撤销的分支状态交付。

## Consequences

- 最终完成的候选数不会超过创建预算，但停止条件命中后仍可能继续获得改善。
- Campaign 进入停止阶段后仍可能运行一段时间并产生 Agent 成本。
- Plan、恢复、复验和 Revert 不消耗优化尝试预算。
